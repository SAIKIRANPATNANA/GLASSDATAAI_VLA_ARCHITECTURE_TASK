🔵 Component 1

Vision Encoder

Processing Flow
RGB Image [224 × 224 × 3] ↓ 16×16 patch split ↓ 196 patch tokens × 1024-dim ↓ DINOv2-ViT-L/14 ↓ Rich spatial features ↓ Perceiver Resampler 196 → 64 tokens ↓ 64 × 4096-dim
Why DINOv2 over CLIP?
CLIP → knows WHAT is in image
DINOv2 → knows WHERE objects are

For grasping, spatial accuracy is everything.
Perceiver Resampler
196 → 64 tokens → 3× faster fusion

Learnable queries compress only task-relevant visual info.
From DeepMind's Flamingo (NeurIPS 2022).
🟢 Component 2

Language Encoder

Processing Flow
"Pick up the red bottle and place it on the table" ↓ BPE Tokenizer vocab = 32,000 tokens ↓ Token IDs: [1, 29347, 701, 278, ...] ↓ LLaMA-3.1-8B (8 billion parameters) ↓ 77 tokens × 4096-dim semantic embeddings
What LLaMA Understands
"red"→ colour attribute
"bottle"→ object class
"pick up"→ action intent
"on the table"→ spatial goal
⚡ KV-Cache Trick
Instruction is static across episode.
Compute once → cache → reuse for 100+ steps.

Saves 40ms per step → critical for 10Hz.

"red" → high attention on red pixels
"bottle" → high attention on bottle shape
"table" → high attention on table surface

Words literally find their visual counterparts.

Real-World Challenges & Solutions

⚡ Latency (8B model too slow)
TensorRT INT8 quantization + KV-cache + 10-step DDIM → 85ms total
🔀 Distribution Shift
Domain randomization in simulation + real-world fine-tuning with 100-200 demos
🔒 Safety
Action clamping + velocity limits + force-torque monitoring → halt on anomaly
💻 Edge Deployment
Distill 8B → 3B + INT8 quantization + NVIDIA Jetson Orin (275 TOPS)
👁️ Object Hallucination
Parallel YOLO-v8 object detector + confidence thresholding → stop if uncertain
🌉 Sim-to-Real Gap
MuJoCo/IsaacSim training + texture/lighting randomization + real demo mixing
